# agent-qa

O agent-qa permite criar e executar testes em linguagem natural para aplicações web, Android e iOS. Combina o mecanismo avançado de memória memidex com autoaperfeiçoamento para reutilizar aprendizados entre execuções.

Requer Node.js 24+ e a configuração do modelo e do navegador ou dispositivo. Usa a licença FSL-1.1-ALv2; provedores de modelos podem cobrar pelo uso.
