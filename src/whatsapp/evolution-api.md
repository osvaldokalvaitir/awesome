# Evolution API

API de código aberto para integração com o WhatsApp. Permite enviar e receber mensagens, gerenciar instâncias e conectar com outras plataformas, como n8n, Typebot e Chatwoot.

Clique [aqui](https://doc.evolution-api.com) para ver a documentação e acessar o serviço.
