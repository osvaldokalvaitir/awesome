# Spec Kit

Toolkit de código aberto do GitHub para desenvolvimento guiado por especificação (Spec-Driven Development) com agentes de inteligência artificial, como GitHub Copilot e Claude Code.

## Documentação e Instalação

Clique [aqui](https://github.com/github/spec-kit) para ver a documentação e fazer a instalação.

Instalar a CLI (requer Python 3.11+ e uv):

```
uv tool install specify-cli
```

Criação de novo projeto:

```
specify init <nome_projeto> --integration <agente>
```

Depois, abra o agente na pasta do projeto e use os comandos `/speckit-*` no chat.
