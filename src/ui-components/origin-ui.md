# Origin UI

Coleção de código aberto com centenas de componentes React e Tailwind CSS no estilo do shadcn/ui, para copiar e colar ou instalar pela CLI do shadcn. Foi adquirida pelo Cal.com e evoluiu para o coss ui.

## Documentação e Acesso ao Serviço

Clique [aqui](https://coss.com/origin) para ver a documentação e acessar o serviço e [aqui](https://coss.com/ui) para acessar o coss ui.
