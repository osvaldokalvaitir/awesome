# React Native FBSDK Next

Wrapper React Native em torno dos SDKs do Facebook para Android e iOS, mantido pela comunidade e sucessor do react-native-fbsdk. Fornece acesso ao login do Facebook, compartilhamento, solicitações de gráficos, eventos de aplicativos, etc.
