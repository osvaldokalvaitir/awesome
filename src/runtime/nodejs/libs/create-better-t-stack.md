# Better T Stack

CLI para criar projetos TypeScript full-stack com tipagem de ponta a ponta, escolhendo o frontend, backend, banco de dados, ORM, autenticação e outras ferramentas.

## Documentação

Clique [aqui](https://www.better-t-stack.dev) para ver a documentação no site ou [aqui](https://github.com/AmanVarshney01/create-better-t-stack) no GitHub.

## Instalação

Clique [aqui](https://www.npmjs.com/package/create-better-t-stack) para fazer a instalação.

Criação de novo projeto pelo npx:

```
npx create-better-t-stack@latest <nome_app>
```
