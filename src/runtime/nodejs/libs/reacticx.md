# Reacticx

Coleção gratuita e de código aberto com mais de 150 componentes animados para React Native, construídos com Expo, Reanimated, Gesture Handler e Skia. Os componentes são copiados para dentro do projeto pela CLI.

## Documentação

Clique [aqui](https://www.reacticx.com) para ver a documentação no site ou [aqui](https://github.com/rit3zh/reacticx) no GitHub.

## Instalação

Clique [aqui](https://www.npmjs.com/package/reacticx) para fazer a instalação.

Iniciar a configuração no projeto:

```
npx reacticx@latest init
```

Adicionar um componente:

```
npx reacticx@latest add <nome_componente>
```
