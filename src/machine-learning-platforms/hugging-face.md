# Hugging Face

Plataforma colaborativa da comunidade de inteligência artificial. Hospeda milhares de modelos, datasets e aplicações (Spaces) de código aberto, além de bibliotecas como Transformers e serviços de inferência para usar os modelos via API.

Clique [aqui](https://huggingface.co) para ver a documentação e acessar o serviço.
